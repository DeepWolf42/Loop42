# License Policy

Loop42 is licensed under the **MIT License**. The root `LICENSE` file is authoritative for Loop42 project code unless a file explicitly states different terms.

## Current rule

- third-party provenance is tracked immediately;
- copied/adapted code requires exact source and license review;
- external tools and CI actions keep their own licenses and are not relicensed by Loop42;
- release/publication still requires a release-specific dependency, file and license audit;
- Loop42 and CORA choose licenses independently;
- no license from CORA, an upstream project or a referenced framework is inherited automatically.

The MIT choice was explicitly approved by the operator during the 2026-09-29 publication-preparation audit after no incompatible vendored implementation dependency was identified on the reviewed basis.
